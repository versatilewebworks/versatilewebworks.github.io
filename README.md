# versatilewebworks.online

A mobile-first serverless typing practice website for stenotypists.

## Features

- Language selection with English, Spanish, French, and German practice text.
- Paste-blocked typing input to keep practice honest.
- AI-style text generation for quick practice passages.
- Speech synthesis playback so users can practice while listening.
- Live WPM, accuracy, elapsed time, and mistake tracking.

## Deployment

Open `index.html` locally or deploy the repository to GitHub Pages / Vercel for a production-ready static site.
